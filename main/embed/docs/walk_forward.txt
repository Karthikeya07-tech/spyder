Twist front walk, 30 s: motor angles
========================================

Files in this folder
  walk_forward_deg.csv    time_s, ID1..ID12  servo degrees 0..300 (150 = middle). The reference walk, unchanged.
  walk_forward_ticks.csv  same rows as AX-12A goal positions 0..1023 (512 = middle)
  walk_forward_rad.csv    same rows as Gazebo joint angles in radians (sim calibration below)
  walk_forward.h          WALK_FRAMES[1026][12] ticks for ESP32 firmware
  neutral_pose.csv          measured neutral pose (robot, 2026-11-02)
  play_action.py        plays the walk on the real robot through the U2D2

Timing: 1026 frames, 30 ms apart = 30.78 s (one 54-frame cycle of 1.62 s, repeated 19 times)
Servos: 12 x AX-12A, 222222 baud, Protocol 1.0. ticks = deg * 1023/300.
The Gazebo playback sends exactly these ticks (checked: 0 tick difference).

Sim calibration (~/twist_ws/src/twist_dxl_walker/config/motor_ids.yaml):
  joint_rad = direction * (ticks - 512 - offset) / 195.38
